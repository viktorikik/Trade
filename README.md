# Trading Signals MVP

Учебный проект: график цены + EMA + сигналы пересечения.

**Стек:** статический HTML/JS, TradingView Lightweight Charts, GitHub Pages.

## Запуск локально

Просто открой `index.html` в браузере. Или подними локальный сервер:

```bash
python -m http.server 8000
# и открой http://localhost:8000
